ID: TC-007
Модуль/фича: Форма создания объявления / Поле «Название» (Заголовок)
Заголовок: Проверка валидации поля «Название» на граничные значения длины (50 символов)
Предусловия:
 1. Тестовое окружение: Windows 10 22H2, Яндекс.Браузер версии 26.8.0.1788 (64-bit), разрешение 2560×1440.
 2. Пользователь авторизован на сайте Авито.
 3. Открыта страница создания нового объявления.
 4. Остальные обязательные поля заполнены валидными данными аналогично TC-002 (категория, состояние, фото, доступность, описание, цена, местоположение, доставка, контакты, тип размещения).
Техника тест-дизайна: Граничные значения (Boundary Value Analysis)
Шаги:
 1. В поле «Название объявления» ввести текст длиной ровно 50 символов, включая пробелы.
 2. Нажать кнопку «Опубликовать».
 3. Дождаться результата.
 4. Очистить поле «Название» и ввести текст длиной 51 символ (то же значение + 1 символ).
 5. Нажать кнопку «Опубликовать».
 6. Дождаться результата.
Тестовые данные:
 Граничное значение (50 символов): «Шторы серого цвета в гостиную из натурального льна» (проверено — ровно 50 символов вместе с пробелами)
 За границей (51 символ): «Шторы серого цвета в гостиную из натурального льна!»
Ожидаемый результат: При 50 символах — заголовок принимается, объявление публикуется без ошибок. При 51 символе — публикация блокируется, показывается сообщение об ошибке по длине поля.
Фактический результат: При 50 символах объявление успешно опубликовано. При 51 символе публикация не прошла — страница прокрутилась к полю «Название», поле подсветилось красным, появилась подпись «Можно ввести до 50 символов».
Статус: Passed
Приоритет: High
