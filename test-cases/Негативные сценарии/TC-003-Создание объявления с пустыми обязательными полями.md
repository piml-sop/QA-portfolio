ID: TC-003
Модуль/фича: Публикация объявления
Заголовок: Проверка невозможности создания объявления без указания цены
Предусловия:
 1. Тестовое окружение: Windows 10 22H2, Яндекс.Браузер версии 26.8.0.1788 (64-bit), разрешение 2560×1440.
 2. Пользователь авторизован на сайте Авито.
 3. Открыта главная страница Авито.
Техника тест-дизайна: Негативное тестирование (проверка валидации обязательного поля)
Шаги:
 1. Нажать на кнопку «+ Разместить объявление» вверху по центру экрана.
 2. Заполнить все поля формы корректными данными (название, категория, состояние, фото, доступность, описание, местоположение, доставка, контакты, тип размещения) — аналогично TC-002.
 3. Поле «Цена» оставить пустым.
 4. Нажать кнопку «Разместить».
Тестовые данные: Все поля заполнены как в TC-002, кроме поля «Цена» — оно намеренно оставлено пустым.
Ожидаемый результат: Объявление не публикуется. Система блокирует отправку формы и указывает пользователю, что поле «Цена» обязательно для заполнения.
Фактический результат: После нажатия «Разместить» страница автоматически прокрутилась вверх к незаполненному полю «Цена», поле подсветилось красным цветом, под ним появился текст «Укажите стоимость». Объявление не было опубликовано.
Статус: Passed
Приоритет: High
