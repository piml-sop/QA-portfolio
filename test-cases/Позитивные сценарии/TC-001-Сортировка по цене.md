ID: TC-001
Модуль/фича: Сортировка по возрастанию цены для неавторизованного пользователя.
Заголовок: Проверка сортировки списка объявлений по цене (от дешёвых к дорогим).
Предусловия:
 1. Тестовое окружение: Windows 10 22H2, Яндекс.Браузер версии 26.8.0.1788 (64-bit), разрешение 2560×1440.
 2. Находимся на главной странице Авито.
 3. В результатах поиска по любому запросу "ножки для стола" присутствует не менее 5 объявлений с разной ценой.
Техника тест-дизайна: Позитивное сценарное тестирование.
Шаги:
 1. Над списком объявлений найти кнопку «Сортировка».
 2. Раскрыть список и выбрать вариант «Дешевле».
 3. Дождаться обновления списка объявлений.
 4. Сравнить цены объявлений последовательно сверху вниз.
Тестовые данные: 
До сортировки (порядок по умолчанию): 36 380 ₽, 35 000 ₽, 16 900 ₽, 46 890 ₽, 34 990 ₽, 3 825 ₽, 27 000 ₽, 44 500 ₽, 1 475 ₽, 24 900 ₽
Ожидаемый результат: После применения сортировки «Дешевле» объявления расположены по возрастанию цены (каждая следующая цена ≥ предыдущей); выбранный вариант сортировки визуально отмечен как активный
Фактический результат: После сортировки цены расположились так: 101 ₽, 102 ₽, 108 ₽, 109 ₽, 110 ₽, 110 ₽, 111 ₽, 112 ₽, 120 ₽, 120 ₽ — строго по возрастанию, нарушений порядка не обнаружено; промо-меток среди этих 10 объявлений не обнаружено. Также обнаружены объявления с одинаковой ценой (110 ₽, 120 ₽) — при этом относительный порядок между ними не нарушает общую сортировку по возрастанию
Статус: Passed 
Приоритет: High
