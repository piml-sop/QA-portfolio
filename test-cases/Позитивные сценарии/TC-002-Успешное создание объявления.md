ID: TC-002
Модуль/фича: Публикация объявления
Заголовок: Успешное создание объявления о продаже ножек для мебели с валидными данными
Предусловия:
 1. Тестовое окружение: Windows 10 22H2, Яндекс.Браузер версии 26.8.0.1788 (64-bit), разрешение 2560×1440.
 2. Пользователь авторизован на сайте Авито.
 3. Открыта главная страница сайта.
Техника тест-дизайна: Позитивное сценарное тестирование
Шаги:
 1. Нажать на кнопку «+ Разместить объявление» вверху по центру экрана.
 2. Выбрать категорию «Для дома и дачи» → «Ножки — комплектующие — столы и стулья».
 3. Ввести название объявления.
 4. Выбрать «Вид продажи» — «Продаю своё».
 5. Указать «Состояние» — «Б/у».
 6. Загрузить 3 фотографии.
 7. В разделе «Доступность» указать «В наличии».
 8. Ввести описание товара.
 9. Ввести цену.
 10. Указать местоположение.
 11. Выбрать способ доставки — «Доставка партнёрами Авито» (за комиссию).
 12. Указать контактные данные (телефон, способ связи).
 13. Выбрать «Тип размещения» — «Автопубликация».
 14. Нажать кнопку «Разместить».
 15. На экране «Продвижение с прогнозом» выбрать «Пропустить».
 16. На экране «Заметный внешний вид» выбрать «Продолжить без услуг».
Тестовые данные:
 Название: «Ножка для мебели круглая ⌀60 мм высота 820 мм хром»
 Категория: Для дома и дачи — Ножки — комплектующие — столы и стулья
 Состояние: Б/у
 Цена: 550 ₽
 Описание: «Ножка мебельная TL-009 — регулируемая опора из стали, рассчитанная на нагрузку в 50 кг...» (полный текст в файле объявления)
Ожидаемый результат: Объявление успешно создано. Появляется сообщение об успешной публикации. Объявление отображается в списке объявлений пользователя и доступно для просмотра по прямой ссылке. Все введённые данные (название, цена, описание) отображаются корректно.
Фактический результат: После нажатия «Разместить» и прохождения экранов «Продвижение с прогнозом» (пропущено) и «Заметный внешний вид» (продолжено без услуг) появилась страница подтверждения успешной публикации.
