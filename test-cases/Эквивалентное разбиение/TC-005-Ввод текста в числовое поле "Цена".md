ID: TC-005
Модуль/фича: Форма создания объявления / Поле «Цена»
Заголовок: Проверка валидации поля «Цена» при вводе текста и невалидных символов
Предусловия:
 1. Тестовое окружение: Windows 10 22H2, Яндекс.Браузер версии 26.8.0.1788 (64-bit), разрешение 2560×1440.
 2. Пользователь авторизован на сайте Авито.
 3. Открыта страница создания нового объявления.
Техника тест-дизайна: Эквивалентное разбиение (невалидные классы входных данных)
Шаги:
 1. В поле «Цена» попытаться ввести значение из списка тестовых данных.
 2. Зафиксировать, принимает ли поле ввод символа.
 3. Повторить для каждого значения из списка.
Тестовые данные: abc / сто / >4 / 4 days / $5.00 / 50+ / test%&тест
Ожидаемый результат: Поле «Цена» не позволяет ввести нечисловые значения.
Фактический результат: Поле физически не позволяет ввести ни один из перечисленных нечисловых символов — при попытке ввода буквы, знаки препинания и спецсимволы просто не появляются в поле. Проверено на всех 7 тестовых значениях.
Статус: Passed
Приоритет: High
